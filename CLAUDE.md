# Writing rules

For anything written for a human reader (emails, outreach, LinkedIn posts, proposals, case studies, web copy, briefs, summaries meant to be sent or shared), always apply both writing skills in `.claude/skills/`:

1. `humanizer` first: remove AI writing patterns and never invent facts. This is the floor.
2. `sharpen` second: apply only the knobs the piece needs, within the humanizer floor.

Use embedded mode: deliver only the final text, not the draft or audit, unless asked for the working.

Where a writing sample for the author exists (for example Jane's or Paulene's sent emails), match that voice. Skip the persuasion knobs for technical, reference and code documentation.
