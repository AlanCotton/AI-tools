Gmail

  1. Press Copy signature.
  2. Settings → See all settings → General → Signature → Create new.
  3. Paste into the box, then Save changes at the bottom.

Outlook

  1. Press Copy signature.
  2. Settings → Mail → Compose and reply (new Outlook: Accounts → Signatures).
  3. Paste, name it "The Taylor", set it as default for new messages.

Apple Mail

  1. Press Copy signature.
  2. Mail → Settings → Signatures → +.
  3. Untick "Always match my default message font", then paste.

The signature is all text and tables, with no images, so it won't be blocked or show as an attachment. Use Copy HTML if your client or a tool like HubSpot asks for signature source code.
